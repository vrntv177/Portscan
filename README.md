## Sobre o projeto

O **Victor PortScan** é uma ferramenta de análise de portas TCP desenvolvida em Python para testes de conectividade, estudos de redes e auditorias autorizadas de segurança

O projeto foi criado com foco em:

- desempenho
- simplicidade de uso
- saída clara no terminal
- identidade visual personalizada

---

## Funcionalidades

- Escaneamento rápido de portas TCP
- Identificação de portas abertas
- Suporte a IPs e domínios
- Execução com múltiplas threads
- Timeout configurável
- Exportação de resultados para arquivo
- Modo de varredura `--top-10k`
- Banner ASCII personalizado no terminal
